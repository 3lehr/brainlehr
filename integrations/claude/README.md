# Claude-Integration

Kopiere die synthetische Vorlage in eine eigene Claude-MCP-Konfiguration und ersetze nur die zwei Platzhalterpfade. Der Server nutzt ausschließlich JSON-RPC über Standard-Ein-/Ausgabe; die Datenbank wird lokal erzeugt.

Die Vorlage enthält bewusst keine privaten Hooks, Projekte, Nutzerwerte oder gespeicherten Wissensinhalte.
