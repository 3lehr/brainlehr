# Lizenz — kurz und ohne Juristendeutsch

**Der Code steht unter der GNU Affero General Public License v3.0 (AGPLv3).**
Vollständiger Text: [`LICENSE`](./LICENSE).

## Für dich als Privatperson, Forscherin, Open-Source-Entwickler

**Kostenlos, ohne Einschränkung.** Lokal nutzen, verändern, forken,
weiterentwickeln — dafür ist es gebaut.

Eine einzige Bedingung: Gibst du eine veränderte Fassung weiter **oder betreibst
sie als Netzwerkdienst für andere**, muss dein Quelltext ebenfalls unter der
AGPLv3 offen sein. Das ist der Unterschied der AGPL zur GPL — sie greift auch
dann, wenn niemand Software „ausliefert", sondern nur einen Dienst anbietet.

## Für Unternehmen

Die AGPLv3 gilt auch für euch — solange ihr sie einhalten könnt. Eine
**kommerzielle Lizenz** braucht ihr, wenn:

- brainlehr in ein Produkt eingebaut wird, dessen Quelltext geschlossen bleiben
  soll, **oder**
- eure Compliance AGPL-Code grundsätzlich untersagt.

Anfragen: siehe Kontakt im Repository.

## Was NICHT unter der AGPLv3 steht

Zwei Dinge im Repo tragen eine eigene Lizenz, und das ist kein Widerspruch —
eine Datei darf eine andere Lizenz haben als das Projekt, solange es ausgewiesen
ist. Beides steht in [`NOTICE`](./NOTICE):

| | |
|---|---|
| `bsi-dev-profile.json` | **CC BY-SA 4.0** — abgeleitet aus der BSI Stand-der-Technik-Bibliothek. Share-Alike: eine Bearbeitung bleibt CC BY-SA 4.0. |
| `auszug-offen/bestand.jsonl` | enthält 1.637 NASA-LLIS-Einträge (US-Bundeswerk, 17 U.S.C. §105 — **nicht an der Primärquelle geprüft**, siehe [`quellen/fremdquellen.json`](./quellen/fremdquellen.json)) |

## Beiträge

Pull Requests sind willkommen. Damit das Projekt später auch kommerziell
lizenziert werden kann, ist dafür ein **Contributor License Agreement** nötig —
siehe `CONTRIBUTING.md`, sobald es eingerichtet ist. Bis dahin: erst Issue,
dann Code, damit niemand umsonst arbeitet.

## Was diese Datei nicht ist

Eine Rechtsberatung. Sie fasst zusammen, was in `LICENSE` und `NOTICE` steht;
im Zweifel gilt der Lizenztext, nicht diese Zusammenfassung.
